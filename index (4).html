LANGKAH FIX DRIVER — WINDOWS 10
1
Download Driver CP210x dari Silicon Labs
Buka browser, pergi ke alamat resmi Silicon Labs:

https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers
Scroll ke bawah → cari "CP210x Windows Drivers" → klik Download VCP (11.x.x)
File yang didownload: CP210x_Windows_Drivers.zip
💡 Kalau tidak bisa akses internet, driver ini juga bisa dicari di Tokopedia/WA grup bengkel — biasanya ada yang share file .zip-nya
2
Extract dan Install
Klik kanan file ZIP → Extract All → buka folder hasil extract.

Di dalam folder ada dua file installer:
CP210xVCPInstaller_x64.exe ← untuk Windows 10/11 64-bit (ini yang kamu butuhkan) CP210xVCPInstaller_x86.exe ← untuk Windows 32-bit (jarang)
Klik kanan CP210xVCPInstaller_x64.exe → Run as Administrator → Next → Finish.
⚠ Harus Run as Administrator! Kalau tidak, driver tidak bisa terinstall sempurna
3
Cabut & Colok Ulang ZEUS ke USB
Setelah install selesai, cabut kabel USB ZEUS dari laptop, tunggu 3 detik, colok lagi.
Windows akan mendeteksi otomatis dengan driver baru.
💡 Tidak perlu restart laptop di Windows 10 — tapi kalau masih bermasalah, coba restart sekali
✓
Verifikasi di Device Manager
Tekan Win + X → Device Manager
Lihat bagian "Ports (COM & LPT)" — seharusnya sekarang muncul:
Silicon Labs CP210x USB to UART Bridge (COM3) ← atau COM4, COM5, dll
Catat nomor COM-nya! Ini yang akan dipakai di aplikasi.
✅ Jika muncul di Ports (COM & LPT) tanpa tanda seru — driver berhasil terinstall!

Test koneksi cepat via PowerShell

# Lihat semua COM port yang tersedia [System.IO.Ports.SerialPort]::GetPortNames() # Output akan menampilkan daftar seperti: COM1 COM3 ← ini kemungkinan ZEUS CP2102
💡 Catat nomor COM ini — masukkan ke aplikasi saat connect nanti
VERIFIKASI ZEUS TERDETEKSI — CEK VID/PID
Buka PowerShell, jalankan command ini untuk konfirmasi chip CP2102 Silicon Labs:
# Cari device CP210x dengan detail VID/PID Get-WmiObject Win32_PnPEntity | Where-Object {$_.Name -like "*CP210*"} | Select-Object Name, DeviceID # Output yang benar jika CP2102 terdeteksi: Name : Silicon Labs CP210x USB to UART Bridge (COM4) DeviceID : USB\VID_10C4&PID_EA60\... # ^^^^ VID 10C4 = Silicon Labs = CP2102 ✓
✅ Jika VID_10C4 muncul → ini memang CP2102 Silicon Labs di dalam ZEUS MST-100P → driver yang benar sudah terinstall

CAPTURE RAW DATA DARI ZEUS — REVERSE ENGINEER FORMAT
Setelah driver terinstall, kita perlu tahu format persis data yang ZEUS kirim ke PC — apakah Honda K-Line binary langsung, atau ZEUS punya format wrapper sendiri. Langkah ini untuk "duplikat" fungsi ZEUS scanner tools.
1
Install Python + pyserial untuk capture data mentah
# Buka CMD/PowerShell, install pyserial pip install pyserial # Lalu buat file capture.py dengan isi berikut
2
Script Python untuk capture data ZEUS
# capture_zeus.py — jalankan dengan: python capture_zeus.py import serial, time, json # ← GANTI COM3 dengan nomor COM ZEUS kamu COM_PORT = "COM3" BAUDS = [9600, 38400, 57600, 115200] def test_baud(port, baud): try: s = serial.Serial(port, baud, timeout=2) s.write(bytes([0x72, 0x05, 0x00, 0xF0, 0x99, 0xF0])) time.sleep(0.5) data = s.read(64) s.close() if data: print(f"[✓] Baud {baud} → respons: {data.hex()}") return baud, data except: pass print(f"[✗] Baud {baud} — tidak ada respons") return None print("=== ZEUS CP2102 DATA CAPTURE ===") for b in BAUDS: result = test_baud(COM_PORT, b) if result: baud, data = result print(f"\n[FOUND] Baud rate: {baud}") print(f"[RAW] HEX: {data.hex().upper()}") print(f"[RAW] ASCII: {data.decode('ascii','ignore')}") # Simpan ke file untuk analisis with open("zeus_capture.txt", "a") as f: f.write(f"BAUD:{baud} HEX:{data.hex().upper()} ASCII:{data.decode('ascii','ignore')}\n") break
💡 Jalankan script ini saat ZEUS terhubung ke motor yang hidup. Output di zeus_capture.txt bisa kamu share ke sini untuk kita analisis format datanya.
3
Capture stream penuh selama 10 detik
# stream_capture.py — capture 10 detik data mentah import serial, time COM = "COM3" # ← ganti sesuai COM port kamu BAUD = 38400 # ← coba 38400 dulu, ganti jika tidak ada data s = serial.Serial(COM, BAUD, timeout=1) print(f"Capturing dari {COM} @ {BAUD} baud selama 10 detik...") start = time.time() all_data = bytearray() while time.time() - start < 10: chunk = s.read(256) if chunk: all_data.extend(chunk) ts = f"{time.time()-start:.2f}s" print(f"[{ts}] {len(chunk)} bytes: {chunk.hex().upper()}") s.close() print(f"\nTotal: {len(all_data)} bytes") with open("zeus_stream.bin", "wb") as f: f.write(all_data) print("Disimpan ke zeus_stream.bin")
4
Analisis format data otomatis
# analyze_zeus.py — analisis format data yang di-capture import re with open("zeus_stream.bin", "rb") as f: data = f.read() print(f"Total bytes: {len(data)}") print(f"HEX: {data.hex().upper()}") print(f"ASCII: {data.decode('ascii','ignore')}") # Cek apakah Honda K-Line binary frame # Frame valid: [0x02][LEN][TYPE][TABLE][...][ CS] if b'\x02' in data: print("\n[DETECT] Format: Honda K-Line binary (0x02 frame start)") # Cek apakah ASCII CSV dari ZEUS if re.search(b'RPM|TEMP|TPS|ECT', data, re.I): print("\n[DETECT] Format: ZEUS ASCII CSV (RPM:x,TPS:y,...)") # Cek frame length pattern (untuk detect protokol) print("\n[BYTES] Pertama 32 bytes:") print(' '.join(f'{b:02X}' for b in data[:32]))
